# Private Communication

## Definition

PRIVATE COMMUNICATION =
AUTHORIZED PARTICIPANTS
+ LIMITED ACCESS
+ CONTROLLED DISCLOSURE

## Channel model

SENDER → AUTHORIZED CHANNEL → AUTHORIZED RECIPIENT

## Core rule

NO AUTHORIZATION ⇒ NO DISCLOSURE

## Distinction

Private communication is not automatically the same as encrypted communication.

Encryption is one technical method that can help protect private communication.

This file records the symbolic privacy model discussed in the session.
