# FIND

## Definition

FIND = locate an existing object or match within a defined search space.

```text
FIND(Q,S) → M
```

Where:

- Q = query or target
- S = search space
- M = matching object(s), or no match

## TCGE sequence

```text
SEARCH → DETECT → MATCH → LOCATE → RECORD
```

## Boundaries

```text
FIND != CREATE
NOT FOUND != DOES NOT EXIST
```

"Not found" establishes only that the specified search did not locate the target.
