# TCGE Axioms

## Definition

AXIOM = a foundational statement accepted as a starting rule within a formal system, rather than proved from other statements inside that system.

```text
A = accepted foundational rule
```

```text
AXIOMS + DEFINITIONS + LOGIC → THEOREMS
```

## TCGE role

An axiom establishes what the system is allowed to assume before a test or derivation begins.

### A1 — Find/Create Separation

```text
FIND != CREATE
```

### A2 — Search Boundary

```text
NOT FOUND != DOES NOT EXIST
```

### A3 — Evidence-State Separation

```text
DEFINED != MEASURED != VERIFIED
```

### A4 — Authorization/Execution Separation

```text
AUTHORIZATION != EXECUTION
```

### A5 — Chronology Separation

```text
ANCHOR TIME != ORIGIN TIME
```

## Evidence Boundary

```text
AXIOM != EMPIRICAL FACT
```

An axiom is accepted as a starting rule within the formal system. Whether the formal system accurately models the physical world is a separate empirical question requiring evidence.

## Simplified

```text
AXIOM = STARTING RULE
```
