# TCGE Operational Axiom Sequence

These entries define operational distinctions used by the TCGE model.

## LIE

```text
LIE = FALSE REPRESENTATION + BELIEF IT IS FALSE + INTENT TO DECEIVE
FALSE != LIE
ERROR != LIE
UNVERIFIED != LIE
```

Intent must not be inferred merely from an incorrect output.

## NO

```text
NO = explicit rejection or non-authorization
NO != ERASE
NO != FALSE
NO != UNVERIFIED
```

A NO records a decision about an action; it does not establish the truth value of the underlying proposition.

## KEY

```text
KEY = value or condition used to identify, access, or unlock a defined operation
KEY + VALIDATION → ACCESS
KEY != AUTHORIZATION
KEY != IDENTITY
KEY != PROOF
```

A key can enable an operation; separate evidence establishes whether the operation occurred.

## GO

```text
GO = permission or signal to proceed
GO + VALID CONDITIONS → ATTEMPT TRANSITION
GO != EXECUTION
GO != PROOF
```

A GO permits or initiates an attempted transition. TCGE independently observes whether the transition occurred.

## Evidence boundary

```text
DEFINED != EXECUTED != MEASURED != VERIFIED
```

These definitions are formal TCGE rules. They do not by themselves establish empirical claims about external systems.
