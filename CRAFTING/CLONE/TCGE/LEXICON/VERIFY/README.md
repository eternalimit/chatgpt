# VERIFY

Completeness and fidelity gate.

Verify:

1. source boundary is explicit;
2. extraction covers the defined source;
3. normalization rules are explicit;
4. unique entries are deduplicated;
5. definitions remain distinct from source occurrence;
6. provenance is retained;
7. completeness claims match available evidence.

```text
COMPLETE LEXICON CLAIM
REQUIRES
COMPLETE SOURCE + COMPLETE EXTRACTION + COMPLETE DEFINITION COVERAGE
```

VERIFIED STRUCTURE != VERIFIED COMPLETE SESSION LEXICON.
