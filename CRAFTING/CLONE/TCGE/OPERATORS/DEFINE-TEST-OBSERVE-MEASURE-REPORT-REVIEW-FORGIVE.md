# TCGE Operator Chain

## Sequence

```text
DEFINE → TEST → OBSERVE → MEASURE → REPORT → REVIEW → FORGIVE
```

## DEFINE

Establish the exact meaning, boundaries, inputs, outputs, and rules of an object or operation.

```text
DEFINE(X) → SPEC(X)
```

```text
DEFINE != CREATE
DEFINE != EXECUTE
DEFINE != VERIFY
DEFINE != PROOF
```

## TEST

Apply the predefined procedure to the defined object or claim.

```text
TEST(SPEC,X) → EVENT
```

## OBSERVE

Record what actually occurred without adding interpretation.

```text
OBSERVE(EVENT) → RECORD
```

## MEASURE

Convert relevant observations into defined quantities or classifications using the predefined measurement method.

```text
MEASURE(RECORD,METHOD) → VALUE
```

## REPORT

Preserve and communicate the result together with provenance, method, and uncertainty.

```text
REPORT(VALUE,PROVENANCE) → RESULT
```

A report cannot contain evidence that was not produced by the preceding steps.

## REVIEW

Examine the complete record against the predefined requirement and evidence rules.

```text
REVIEW(REPORT,REQUIREMENT,EVIDENCE) → FINDINGS
```

Review does not silently alter the underlying record.

## LIE boundary

A lie requires:

```text
FALSE REPRESENTATION
+ BELIEF IT IS FALSE
+ INTENT TO DECEIVE
```

Therefore:

```text
FALSE != LIE
ERROR != LIE
UNVERIFIED != LIE
```

TCGE does not infer deceptive intent merely because a report is wrong.

## FORGIVE

Release a claim of personal resentment or retaliation while preserving the factual record.

```text
FORGIVE = RELEASE GRIEVANCE WITHOUT ERASING EVIDENCE
```

```text
FORGIVE != ERASE
FORGIVE != DENY
FORGIVE != VERIFY
FORGIVE != EXONERATE
```

A record can remain FALSIFIED, ERRONEOUS, or UNVERIFIED after forgiveness.

## Evidence boundary

```text
DEFINED != EXECUTED != OBSERVED != MEASURED != REPORTED != REVIEWED != VERIFIED
```
