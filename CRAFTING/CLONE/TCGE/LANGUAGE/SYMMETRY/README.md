# TCGE — SYMMETRY

## Definition

Symmetry is a property where a transformation or exchange leaves the relevant structure unchanged.

```text
SYMMETRY = INVARIANCE UNDER A DEFINED TRANSFORMATION
```

Formally, if T is a transformation and S is a system:

```text
T(S) ≡ S
```

with respect to the property being tested.

## Four-sector toy model

In the TCGE four-sector toy model, symmetry means each sector is treated by the same rule and has the same number of winning states.

```text
ID = EGO = SUPEREGO = NOTHING
```

This expresses structural opportunity within the model, not equality of meaning or identity.

## Boundaries

```text
SYMMETRY != EQUALITY OF IDENTITY
SYMMETRY != TRUTH
SYMMETRY != BALANCE IN EVERY OBSERVATION
```

## Simplified

```text
SYMMETRY = SAME STRUCTURE AFTER AN ALLOWED CHANGE
```
