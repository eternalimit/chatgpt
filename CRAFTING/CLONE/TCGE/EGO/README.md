# TCGE — EGO

Status: PRODUCED / COMMITTED

## Definition

EGO = SELF-MODEL

Reduced form:

INPUT
→ SELF_MODEL
→ INTERPRETATION
→ RESPONSE
→ REVIEW

## INPUT

Perception, memory, feedback, emotion, and other internal/external signals.

## SELF_MODEL

Identity, beliefs about self, boundaries, goals, self-image, and perceived status/control.

## INTERPRETATION

Meaning assigned to input relative to the self-model.

## RESPONSE

Thought, decision, communication, or behavior produced after interpretation.

## Boundaries

EGO != PERSON
EGO != FACT
EGO != EMOTION
EGO != EXTERNAL REALITY
INTERPRETATION != OBSERVATION
OUTPUT != VERIFIED REALITY

## Governing rule

The ego may interpret experience; it does not define external reality.
