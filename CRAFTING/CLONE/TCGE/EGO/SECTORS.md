# TCGE Four-Sector Model

The bounded toy model defines:

```text
SYSTEM = {ID, EGO, SUPEREGO, NOTHING}
```

## Sectors

- ID — impulse, drive, immediate want.
- EGO — self-model, mediation, reality checking.
- SUPEREGO — internalized rules, values, standards.
- NOTHING — no action / preserve current state.

```text
ID != EGO != SUPEREGO != NOTHING
NOTHING != FAILURE
```

A bounded decision form is:

```text
INPUT
→ {ID, EGO, SUPEREGO, NOTHING}
→ REVIEW
→ ACTION / NO ACTION
```

This is a TCGE toy decision architecture, not a validated model of human psychology.
