# TCGE Gravity Vectors
## A Bounded Framework for Separating Gravitational Phenomenon from Experimental Production of Measurable Effects

**Preprint v0.1**

**Author:** Richard Stein  
**Framework:** TCGE  
**Status:** Proposed conceptual and experimental framework

## Abstract

This preprint proposes a bounded TCGE framework for representing gravity through two distinct vectors.

Vector A represents the physical/model relationship between a source of gravitation and a gravitational effect:

```text
V_A:
M → FIELD → FORCE → ACCELERATION
```

Vector B represents the experimental process used to investigate and measure a gravitational effect:

```text
V_B:
DEFINE → BUILD → TEST → OBSERVE → MEASURE → REPORT → REVIEW → VERIFY
```

The vectors are intentionally separated.

```text
V_A != V_B
```

The framework does not equate producing a measurable gravitational effect with creating gravity, and does not treat measurement as proof of a new gravitational theory.

## 1. Definition of gravity

For this framework:

```text
GRAVITY = gravitational interaction and its measurable effects
```

Newtonian reference model:

```text
F = G m1 m2 / r^2
g(r) = GM / r^2
```

Near Earth's surface:

```text
g ≈ 9.81 m/s^2
```

General relativity is retained as the relativistic reference description in which gravitation is represented through spacetime geometry.

The TCGE vectors are not claimed here as a replacement for established gravitational theory.

## 2. Vector A — Physical / model vector

```text
V_A:
M → FIELD → FORCE → ACCELERATION
```

Vector A represents the modeled physical relationship.

```text
MODEL != EXPERIMENT
```

## 3. Vector B — Experimental vector

```text
V_B:
DEFINE
→ BUILD
→ TEST
→ OBSERVE
→ MEASURE
→ REPORT
→ REVIEW
→ VERIFY
```

Each stage remains distinct.

## 4. Vector independence

```text
V_A != V_B
BUILD APPARATUS != CREATE GRAVITY
MEASURE GRAVITATIONAL ACCELERATION != DISCOVER NEW THEORY
```

The vectors intersect at the measurable physical effect:

```text
FIELD → PHYSICAL EFFECT → OBSERVATION → MEASUREMENT
```

## 5. Proposed TCGE gravity axioms

### G1 — Phenomenon Separation

```text
GRAVITY != EXPERIMENT
```

### G2 — Vector Separation

```text
V_A != V_B
```

### G3 — Measurement Boundary

```text
MEASUREMENT → EVIDENCE
EVIDENCE ⇏ ANY CLAIM WITHOUT A DEFINED DERIVATION
```

### G4 — Control Requirement

Relevant controls and initial conditions should be specified before testing.

```text
CONTROL → COMPARABILITY
```

### G5 — Model Separation

```text
PREDICTION != OBSERVATION
```

### G6 — Reproducibility

```text
METHOD + CONDITIONS → REPEATABLE TEST
```

### G7 — Uncertainty Preservation

```text
MEASUREMENT = (VALUE, UNCERTAINTY)
```

### G8 — Verification Boundary

```text
VERIFIED RESULT != UNIVERSAL THEORY
```

## 7. Control structure

Potential controls include:

- instrument calibration
- reference-frame definition
- air resistance
- electromagnetic interference
- vibration
- temperature
- timing accuracy
- initial position
- initial velocity
- sensor bias

The framework does not assume that the gravitational component is isolated merely because the experiment is called a gravity experiment.

## 8. Falsification

A proposed gravitational claim should specify observations that would count against it.

```text
H → P
```

where H is the hypothesis and P is its predicted observation.

```text
FAILED TEST != FAILED UNIVERSE
```

The scope of falsification must match the scope of the hypothesis.

## 9. Proposed research program

### G-001

Measure local gravitational acceleration.

### G-002

Change the test mass while holding relevant conditions constant.

### G-003

Measure gravitational effects from a controlled nearby mass configuration.

### G-004

Compare measured results against competing models whose predictions are distinguishable.

## 10. Evidence classification

```text
VERIFIED
FALSIFIED
UNVERIFIED
INVALID
```

An UNVERIFIED result does not become VERIFIED by interpretation alone.

## 11. Limitations

This preprint does not introduce a new physical theory of gravity.

The TCGE gravity vectors are a proposed organizational and epistemic formalism for separating physical models, experimental procedures, observations, measurements, evidence, and verification.

Independent assessment and empirical testing remain required.

## 12. Conclusion

```text
V_A:
M → FIELD → FORCE → ACCELERATION

V_B:
DEFINE → BUILD → TEST → OBSERVE → MEASURE → REPORT → REVIEW → VERIFY
```

The central principle is:

```text
A physical phenomenon and the procedure used to establish evidence about it are not the same object.
```
