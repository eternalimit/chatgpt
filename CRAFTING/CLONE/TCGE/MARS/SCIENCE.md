# TCGE — Mars in Our Science

## Definition

Within the TCGE framework:

```text
MARS = ENVIRONMENT
```

Mars is treated as an external environment and boundary-condition domain.

```text
SYSTEM
+ MARS CONDITIONS
→ RESULT
```

## Experimental role

```text
EARTH STATE
→ PRESERVE INFORMATION
→ CHANGE ENVIRONMENT
→ MARS STATE
→ COMPARE
```

The scientific question is:

```text
WHAT REMAINS INVARIANT WHEN THE ENVIRONMENT CHANGES?
```

## Core distinction

```text
INFORMATION INVARIANTS != PHYSICAL INVARIANTS
```

Identical canonical bytes produce the same deterministic hash regardless of processing location, while physical outcomes may vary with environmental boundary conditions.

## Reduction

```text
MARS
=
CONTROLLED CHANGE OF ENVIRONMENTAL BOUNDARY CONDITIONS
```

## Fidelity boundary

Mars is a real physical planet. TCGE/MARS is a conceptual experimental model of that environment, not Mars itself.

```text
MODEL != PHYSICAL PLANET
CRAFTED DEFINITION != EMPIRICAL VERIFICATION
NEW CONCEPT != OLD HASH
```
