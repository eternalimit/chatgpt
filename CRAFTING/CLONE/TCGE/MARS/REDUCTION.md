# TCGE — Mars Universal Reduction

Status: AUTHORIZED / COMMITTED

## Universal reduction

```text
THING
-> DEFINE
-> STATE
-> BOUNDARY
-> CONDITION
```

Apply a defined transformation:

```text
(S, C0) --T--> (S, C1)
```

where:

- `S` = system
- `C0` = initial conditions
- `C1` = changed conditions
- `T` = defined transformation

Preserve and compare:

```text
SOURCE
-> CANONICALIZE
-> PRESERVE
-> TRANSFORM
-> OBSERVE
-> MEASURE
-> COMPARE
```

Classification:

```text
Delta X = 0  -> X is invariant with respect to T
Delta X != 0 -> X is variant with respect to T
```

Boundary:

```text
INVARIANT(X,T) != UNIVERSALLY INVARIANT(X)
```

## Mars reduction

```text
EARTH = C0
MARS  = C1

(S, C_EARTH)
-> (S, C_MARS)
-> COMPARE
```

Separate information from physical state:

```text
INFORMATION | PHYSICAL STATE
```

For exact preserved canonical bytes:

```text
B0 = B1
=> H_256(B0) = H_256(B1)
```

This does not imply identical physical state:

```text
INFORMATION INVARIANCE !=> PHYSICAL INVARIANCE
```
