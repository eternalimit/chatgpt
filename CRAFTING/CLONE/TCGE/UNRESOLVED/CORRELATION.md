# TCGE — UNRESOLVED CORRELATION

## Reduced chain

```text
OBSERVE → CORRELATE → UNRESOLVED
```

## Definition

UNRESOLVED = an observed relationship or correlation for which the mechanism, cause, interpretation, or evidentiary bridge has not been established.

## Image-correlation example

One image can contain a defined mathematical center/vector/offset point while another image contains a bright source and an offset optical point.

A visual correspondence may therefore be recorded:

```text
CENTER / SOURCE → OFFSET POINT
```

without concluding that both observations share the same physical cause.

## Boundaries

```text
VISUAL MATCH != CAUSAL MATCH
CORRELATION != CAUSATION
SHAPE MATCH != MECHANISM MATCH
OBSERVATION != INTERPRETATION
UNRESOLVED != FALSE
UNRESOLVED != VERIFIED
```

## Reduced rule

```text
MATCH IN SHAPE != MATCH IN CAUSE
```

An unresolved state preserves the observation and the correlation while withholding a causal conclusion.
