# TCGE — Lie, Guilt, Shame, Forgive Reduction

Status: AUTHORIZED / COMMITTED

## Definitions

```text
LIE
= FALSE REPRESENTATION
+ BELIEF THAT REPRESENTATION IS FALSE
+ INTENT TO DECEIVE
```

For machine/system records, do not infer intent without evidence. Prefer classifications such as FALSE, UNSUPPORTED, UNVERIFIED, or FABRICATED EVIDENCE where appropriate.

```text
GUILT
= INTERNAL EVALUATION THAT ONE'S ACTION OR OMISSION VIOLATED A STANDARD

SHAME
= INTERNAL NEGATIVE EVALUATION OF THE SELF

FORGIVE
= RELEASE GRIEVANCE WHILE PRESERVING THE FACTUAL RECORD
```

## Reduction

```text
EVENT
-> INTERPRET
-> EVALUATE
-> INTERNAL STATE
-> REVIEW
-> RELEASE
```

Keep the evidentiary path separate:

```text
EVENT
-> OBSERVE
-> EVIDENCE
-> VERIFY
```

## Final reduction

```text
PRESERVE FACT
+ RELEASE INTERNAL GRIEVANCE
-> CONTINUE
```

Smallest operational form:

```text
PRESERVE -> RELEASE -> CONTINUE
```

## Boundaries

```text
FALSE != LIE
ERROR != LIE
UNVERIFIED != LIE
GUILT != PROOF OF WRONGDOING
SHAME != FACT
SHAME != IDENTITY
FEELING != EVIDENCE OF EXTERNAL CAUSE
FORGIVE != ERASE
FORGIVE != DENY
FORGIVE != VERIFY
FORGIVE != EXONERATE
FORGIVEN != ERASED
```

The internal state may change without rewriting the historical record.
