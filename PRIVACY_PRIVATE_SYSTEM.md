# Privacy — Private System

## Core definition

PRIVATE SYSTEM = ACCESS LIMITED BY CONTEXT + PERMISSION

PRIVACY = CONTROLLED INFORMATION FLOW

## Model

IDENTITY → CONSENT → ACCESS → USE → RETENTION

## Distinctions

- Private = not openly available to everyone.
- Privacy = control over personal information and who can access or use it.
- Context-limited access = information is used only within the permitted context.
- Identity claim ≠ identity verification.
- Private system ≠ anonymous system.

## Core rule

NO PERMISSION ⇒ NO ACCESS
