UFAMILY(U,R) = { x in U | x participates in R }

## UPT

UPT is defined here as:

UPT = UNIVERSAL POINT TOKEN

A UPT is a framework-level symbolic point that identifies one explicitly defined unit within a universe U.

UPT(U, x) = a symbolic point assigned to x, where x is explicitly admitted to U.

Thus:

UNIT -> UPT -> U

and for a sequence:

x1 -> x2 -> ... -> xn
maps to
UPT1 -> UPT2 -> ... -> UPTn

A UPT preserves a defined symbolic identity for correlation inside the framework.

Boundaries:

UPT != LLM TOKEN
UPT != TOKEN ID
UPT != BYTE
UPT != HASH
UPT != EMPIRICAL PROOF

"Upt" is a framework term defined by this record; this definition does not claim that the term has this meaning in established tokenizer science.
