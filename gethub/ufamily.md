# Family / UFamily

## Preserved source

Family. Ufamily.

## Definitions

U = UNIVERSE / defined domain under consideration.

FAMILY = a related set whose membership is determined by a specified relation.

UFAMILY = a family whose membership is defined within U.

For a universe U and relation R:

UFAMILY(U,R) = { x in U | x participates in R }

## Correlation

U -> UFAMILY -> FAMILY

When a particular FAMILY is explicitly admitted to UFAMILY:

MEMBER in FAMILY subseteq UFAMILY subseteq U

The inclusion is conditional on the relevant membership definitions.
