## Definitions

### 0

Within this framework:

0 = ZERO UNITS

When a binary state mapping is explicitly defined:

0 = OFF

Zero is a defined value and must not be silently equated with metaphysical nothingness.

### 1

Within this framework:

1 = ONE UNIT

When a binary state mapping is explicitly defined:

1 = ON

### Primitive pair

0 <-> 1

0 = absence of the counted state
1 = one unit of the counted state

## Relation

0 -> 1 -> UNIT -> UNIVERSE -> UNIVERSAL

## Boundaries

ZERO != NOTHING

1 != ALL

BINARY VALUE != TRUTH VALUE unless that mapping is explicitly defined.

ONE TRUE UNIT != UNIVERSAL TRUTH
