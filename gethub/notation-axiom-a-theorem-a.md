# Notation → Axiom A → Theorem A

## Notation

```
N_A = On.no
```

`.` is initially a **separator**, not a transition operator.

## Axiom A — Separation

```
On.no ≢ ON → NO
```

**Axiom A:** An ordered notation does not, by itself, establish a state transition.

## Theorem A — Transition Requirement

Given Axiom A:

```
ON → NO  ⇒  ∃ T : T(ON) = NO
```

Within this formal system, asserting an ON-to-NO transition therefore requires a defined transition relation/operator `T`.

## Hierarchy

```
NOTATION → AXIOM A → THEOREM A
```

## Boundary

```
THEOREM WITHIN THE FORMAL SYSTEM
≠
EMPIRICALLY VERIFIED PHENOMENON
```

Theorem A is tied to the declared formal definitions and axioms. This record does not treat the theorem as experimental proof of an external physical phenomenon.
