## Defined sequence

SIGNATURE → AUTHORIZE → COMMIT

- SIGNATURE: the recorded declaration associated with the stated identity and intent.
- AUTHORIZE: explicit instruction permitting the specified repository action.
- COMMIT: creation of the resulting Git repository record.

This record documents the declaration and Git action; it does not by itself constitute a cryptographic digital signature or independently establish legal ownership or identity.
