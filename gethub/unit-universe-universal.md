## Definitions

### UNIT

A UNIT is one explicitly identified member, object, or measurement element within a defined domain.

UNIT(x) = one identified x in domain U

### UNIVERSE

The UNIVERSE is the explicitly defined domain containing the units under consideration.

U = {x | x belongs to the defined domain}

### UNIVERSAL

UNIVERSAL is a scope operator over the defined universe.

UNIVERSAL_U(P) iff for all x in U, P(x)

## Relation

UNIT -> UNIVERSE -> UNIVERSAL

Reduced:

ONE -> DOMAIN -> ALL-IN-DOMAIN

## Boundaries

UNIT != UNIVERSE

UNIVERSE != UNIVERSAL

ONE TRUE UNIT != UNIVERSAL TRUTH

A universe names a domain. Universal quantification ranges over that domain. A single unit does not establish a universal proposition.
