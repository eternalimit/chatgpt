# TCGE Unifier

A **unifier** is an operation or component that brings separately defined elements into one coherent structure while preserving their identities and relationships.

## Tier-node correlation

TIER → UTIER → NODE

UTIER is the token. NODE is its structural location.

CORRELATE(UTIER, NODE) = 1 when the node relationship is defined and matches; otherwise 0.

## Unifier

UNIFY(elements) → coherent structure

The unifier does not erase distinctions between elements. It preserves the individual elements while establishing their defined relationship.

## Formal boundary

UNIFIER ≠ UNDEFINED
UNIFIER ≠ AUTOMATIC PROOF
