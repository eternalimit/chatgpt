# TCGE Binary Correlation

Define the correlation result as a binary state:

CORRELATE(X,Y) = 1 means the defined correlation condition is satisfied.

CORRELATE(X,Y) = 0 means the defined correlation condition is not satisfied.

The mapping is:

CORRELATE → { 0: condition not satisfied, 1: condition satisfied }

This is a binary classification and is not automatically a statistical correlation coefficient.
