# TCGE Action

Action is a change, movement, interaction, or operation occurring over time.

ACTION = ΔSTATE / Δt

For a wave state z(x,y,t):

ACTION(x,y,t) = ∂z(x,y,t) / ∂t

Given:
z(x,y,t) = A sin(k_x x + k_y y - ωt + φ)

then:
∂z/∂t = -ωA cos(k_x x + k_y y - ωt + φ)

Still:
STILL = z(x,y,t₀)

Action:
ACTION = ∂z/∂t

A still represents one defined state. Action requires change across time.
