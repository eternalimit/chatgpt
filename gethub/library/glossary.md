# Glossary

- **Anchor** — fixed reference point used for comparison.
- **Boundary** — explicit limit on an inference, operation, or claim.
- **Code** — structured representation interpreted under defined rules.
- **Evidence** — recorded information relevant to evaluating a claim.
- **Library** — organized collection of addressable objects.
- **lib** — GetHub address/reference layer for the Library.
- **TCGE** — framework operator/system name used by this project; meaning is bounded by its committed definitions.
- **Unit** — one explicitly identified member or measurement element in a domain.
- **Universe** — explicitly defined domain of objects under consideration.
- **Universal** — scope over every member of a defined domain.
- **UTRUTH** — framework label for a universal proposition supported over its explicitly defined domain.
- **UTURTH** — provisional reverse-audit operator that traces a claim back through its derivation.
