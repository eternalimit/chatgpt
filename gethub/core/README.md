# GetHub Core

GetHub is the outer knowledge/provenance layer. GitHub/Git records remain source objects.

Core pipeline:

OBJECT -> IDENTITY -> INDEX -> RETRIEVE -> DEFINE -> CLAIM -> TEST -> EVIDENCE -> VERIFY/FALSIFY -> RECORD

Boundaries:

INDEX != CONTENT
DEFINED != VERIFIED
PRODUCED != CORRECT
CORRELATION != EQUIVALENCE
EVIDENCE != PROOF
ORDER != CAUSATION != VERIFICATION

The core is append-oriented: corrections add records; they do not silently erase prior evidence.
