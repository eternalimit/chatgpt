### Precise evidence-authentication boundary
A cryptographically valid signature guarantees only authenticity *relative to the public key and signed bytes*, **assuming that key has been bound to a trusted principal externally**. The signature alone does not establish checker independence, reproducible scientific correctness or absence of collusion. Even a caller-provided boolean `independently_certified_identity=True` cannot be trusted without a separately authenticated and pinned trust registry. A035's verifier is a review-only proof-of-concept with conditional trust inputs, **not** a production trust service. Nothing in it produces an authenticated external Echo for existing research claims.

### Formal indistinguishability observation (conditional)
Let decision function D depend solely on claim bytes, caller-controlled origin labels, caller-controlled flags and an unattested signature claim. Construct two possible real-world scenarios with identical D inputs: (i) an independent checker actually ran; (ii) the claimant invented both labels and flags. D returns the same answer in both worlds, so D cannot soundly certify independent Echo in all cases using only those inputs. External trust anchoring (validated key ownership/issuer identity, checker byte-hash pinning, independently verified result and provenance) is a necessary *additional* evidence interface. This is a logical limitation of the specified information available to D, not a new mathematical result about P versus NP or physical reality.
