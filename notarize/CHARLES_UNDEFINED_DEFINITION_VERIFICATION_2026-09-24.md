# Charles Verification — Undefined

Date: 2026-09-24

## Definition

Undefined means:

> No valid value is assigned by the stated rule at that input.

## Tangent example

For

tan(x) = sin(x) / cos(x)

when

cos(x) = 0

the expression requires division by zero, so tangent is undefined at

x = pi/2 + k*pi,  k in Z.

## Distinctions

undefined != unknown

undefined != unverified

Unknown or unverified concerns what has not been established.

Undefined concerns the rule itself: the rule assigns no valid value at that input.
