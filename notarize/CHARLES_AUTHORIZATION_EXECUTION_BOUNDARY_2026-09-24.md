# Charles Verification — Authorization–Execution Boundary

Date: 2026-09-24

## Definition

Authorize means:

> To give explicit permission for a specific action to occur.

## Workflow

Prepare
→ Present
→ Authorize
→ Execute
→ Verify

## Boundary

Intent != Authorization != Execution

Authorization is the gate between proposal and action.

## Governing rule

No execution without prior authorization.

## Scope

VERIFIED as a workflow/governance rule for actions that require explicit confirmation.

This is not asserted as a universal law of all systems.
