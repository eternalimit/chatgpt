# ASH Core — Action Skill Snapshot

## Architecture

POINT → STATE → SKILL → ACTION → RESULT

## Snapshot

- POINT: Defined node
- STATE: Current condition
- SKILL: Available capability
- ACTION: Selected operation
- GATE: Permission / condition
- RESULT: Observed output
- VERIFY: Evidence check
- HANDOFF: TCU state transfer
- EXPORT: Packaged record
- ENGINE: ASH Core
- INTERFACE: TXGE Vision
- ROOT: PROMPT

## Rule

SKILL ≠ ACTION

A skill is a capability; an action is an operation performed using that capability.

## Status

This is a conversation-defined architecture specification, not a claim that a physical ASH Core has been manufactured or deployed.
