# BITY with -• separator

## Definition

Insert the literal separator `-•` between every original letter of `BITY`.

Result:

B-•I-•T-•Y

## General rule

For an original sequence:

A1 A2 A3 ... An

the transformed form is:

A1(-•)A2(-•)A3...(-•)An

This file records the symbolic transformation exactly as defined in the session.
