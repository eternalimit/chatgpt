# Atomic Plumbing Glyph Alphabet

Date: 2026-09-26

## Purpose

Define a compact symbolic plumbing alphabet for representing atomic plumbing components, flow, control, and operators.

## Canonical Glyph Set

### Components

- Source = `•`
- Valve / gate = `|`
- Check valve = `>|`
- Pump / pressure = `^`
- Faucet / outlet = `┐`
- Shot / nozzle = `>`
- Fountain = `♨`
- Sink / receiver = `∪`
- Pint glass = `∪|`
- Tank / reservoir = `□`
- Trap = `U`
- Tee = `T`
- Wye / branch = `Y`
- Elbow / turn = `⌞`
- Coupling / union = `=`
- Reducer = `>-<`
- Regulator = `≈`
- Meter = `#`
- Filter = `◇`
- Cleanout / reset access = `○`
- Point / terminal = `.`

### Flow / Control

- Pipe / flow = `→`
- Reverse flow = `←`
- Closed gate = `||`
- Drain = `↓`
- Vent = `↑`
- Overflow = `↗`
- Pour = `~>`

### Logic / Operators

- Two-way / opposition = `><`
- Loop = `↻`
- Flip-flop = `⇄`
- Copy = `:`
- Offset +1 = `+1`
- Link = `—`
- Orientation = `↦`

## Compact Alphabet

`• → ← >< | || >| ^ ┐ > ♨ ∪ ∪| □ U ↓ ↑ ↗ T Y ⌞ = >-< ≈ # ◇ ○ . ↻ ⇄ : +1 — ↦ ~>`

## TCGE Boundary

This artifact defines a symbolic language and internal notation system.

- Reality: user-defined glyph meanings and sequence examples are directly supplied.
- Inference: the grouped categories and reducer disambiguation are derived organization choices.
- Echo: independent validation against plumbing code, hydraulics, drafting standards, or field construction has not been established here.

Therefore, the notation is preserved as a governed symbolic representation, not as independently validated plumbing design notation.
