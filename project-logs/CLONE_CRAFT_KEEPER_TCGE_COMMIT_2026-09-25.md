## Core cycle

`ADD -> CRAFT -> BUILD -> PRODUCE -> TCGE -> HOLD -> KEEP / KEEPER`

- ADD / ADDER introduces new information or a proposed change.
- CRAFT solves using explicit knowledge, tacit knowledge, spatial reasoning, and experience.
- BUILD converts the solution into a coordinated, constructible definition.
- PRODUCE executes the coordinated solution in the real world.
- TCGE governs validation.
- HOLD preserves validated state.
- KEEP / KEEPER maintains continuity and the authoritative coordinated model.

Working key:

> Add creates change. Craft solves it. Build defines it. Produce realizes it. TCGE validates it. Hold preserves it. Keeper maintains continuity.

## Shop-drawing correlation

Working coordination flow:

`mechanical/design intent + architectural floor plan + structural plan + field conditions -> overlay/coordination -> clash detection -> candidate reroute -> validation -> coordinated shop drawing -> field verification`

Examples of constraints include beams, footings, walls, elevations, pipe size, grade, fittings, venting, and physical installation space.

A diagrammatic design route is not, by itself, proof of constructability. A proposed reroute remains a candidate until the governing constraints are checked.

## Craft Intelligence

Working definition:

`Craft Intelligence = explicit knowledge + tacit knowledge + engineering elegance + TCGE validation`

Science establishes constraints. Craft applies judgment within those constraints. Art/engineering elegance describes selection of a clean, efficient, serviceable, constructible solution among valid alternatives.
