# Focus → Aim → Point → Solution → Resolution → Resolve

## Definitions

- FOCUS = concentrate attention on a defined subject.
- AIM = establish intended direction or objective.
- POINT = specify the target or reference.
- SOLUTION = satisfy the defined problem and constraints.
- RESOLUTION = settling a defined problem or specifying distinguishable detail.
- RESOLVE = determine, settle, or bring to a definite state.

## Chain

\[
\boxed{\text{FOCUS}\rightarrow\text{AIM}\rightarrow\text{POINT}\rightarrow\text{SOLUTION}\rightarrow\text{RESOLUTION}\rightarrow\text{RESOLVE}}
\]

## Operational reduction

\[
\boxed{\text{FOCUS}+\text{AIM}+\text{CONSTRAINTS}\rightarrow\text{RESOLVE}}
\]

## Evidence boundary

Resolution is not proof. A resolved problem may still require independent verification of any factual or empirical claim.

\[
\boxed{\text{RESOLUTION}\neq\text{PROOF}}
\]
