# Evidence State Vocabulary

## Four-state reduction

\[
\boxed{
\text{RELEVANT}\;|\;\text{TRUE}\;|\;\text{FALSE}\;|\;\text{UNDEFINED}
}
\]

### Relevance
Relevant = applicable or materially connected to the defined question or domain.

Related terms:
- applicable
- pertinent
- connected
- material
- significant
- consequential

### True
True = consistent with the defined facts, rules, or sufficient evidence.

Related terms:
- factual
- accurate
- correct
- valid
- verified
- confirmed
- substantiated

### False / Fake
False = contradicted by the applicable facts, rules, or evidence.

Related terms:
- fabricated
- counterfeit
- fictitious
- erroneous
- invalid
- unsupported

"Fake" is context-dependent and should not automatically be treated as equivalent to every kind of false statement.

### Undefined
Undefined = not sufficiently specified or determined.

Related terms:
- unknown
- unspecified
- unresolved
- indeterminate
- ambiguous
- undetermined
- unverified

## Evidence gate

\[
\boxed{
\begin{aligned}
\text{VERIFIED} &\rightarrow \text{TRUE}\
\text{CONTRADICTED} &\rightarrow \text{FALSE}\
\text{INSUFFICIENT EVIDENCE} &\rightarrow \text{UNDEFINED}\
\text{OUTSIDE DOMAIN} &\rightarrow \text{IRRELEVANT}
\end{aligned}}
\]

## Preservation distinctions

\[
\boxed{\text{UNDEFINED}\neq\text{FALSE}}
\]

\[
\boxed{\text{IRRELEVANT}\neq\text{FALSE}}
\]

The classifications are distinct and should not be silently collapsed.
