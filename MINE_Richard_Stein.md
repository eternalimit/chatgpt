# MINE

## Representation, Action, Evidence, and Ownership

**Master copy / architecture record**

### Core thesis

MINE distinguishes among an idea, its representation, a record, evidence, and ownership.

\[
\boxed{\text{CLAIM}\neq\text{RECORD}\neq\text{PROOF}\neq\text{OWNERSHIP}}
\]

### TXGE interface

PROMPT → TRANSFORM → EXECUTE → GATE → EVALUATE → RESULT → EXPORT

### Core principles

1. Define the object of a claim.
2. Preserve the original input.
3. Keep representations distinct from what they represent.
4. Separate execution from evaluation.
5. Preserve handoff state.
6. Mark uncertainty explicitly.
7. Verify external actions independently.
8. Do not infer ownership from a record alone.
9. Package results at the end of a workflow.
10. Preserve provenance and chronology.
