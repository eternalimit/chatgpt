# Fidelity → Resolve → Max → Point

## Core axiom

0 → FIDELITY → RESOLVE → MAX → •

## Definitions

0 = start / minimum

FIDELITY = preserve evidence, provenance, chronology, identity, and uncertainty boundaries

RESOLVE = advance state only as far as verification supports

MAX = 1

• = current resolved reference state

## Normalized bound

0 ≤ • ≤ 1

## Governing rule

FIDELITY → RESOLUTION ≤ VERIFICATION

## Compact token

0•1

FIDELITY + RESOLVE define the transition discipline between the minimum and maximum normalized states.

## Evidence boundary

MAX = 1 is a framework normalization, not a claim of absolute truth.
