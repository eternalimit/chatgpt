CREW

CREW = Coordinated Roles for Execution & Work

A project-defined dynamic operating model for a group of distinct functional roles that coordinate work while preserving role boundaries, provenance, governance, and return state.

Definition

CREW is the execution-oriented counterpart to a cast of named roles. A CAST identifies who or what the functional roles are. CREW describes how authorized roles coordinate around a task.

CAST = WHO / ROLE IDENTITY
CREW = HOW ROLES COORDINATE WORK

Core CREW Functions

Coordinate Route the task to the appropriate role without silently collapsing role identities.

Resolve Determine the referenced object, instruction, state, and required evidence before execution.

Execute Perform only the authorized operation using the frozen input and parameters.

Witness Preserve observations, outputs, provenance, unresolved conditions, and return state.

Governance Invariants

  • No role silently substitutes for another role.
  • No unresolved reference is treated as resolved.
  • No generated representation establishes historical provenance by itself.
  • No execution result rewrites an earlier frozen checkpoint.
  • A hash establishes measured byte identity of the saved artifact, not semantic truth or independent Echo.
  • Knowledge remains governed by K = R ∧ I ∧ E when TCGE is applied.
