# Program Action Plan

## Root sequence

PROGRAM → PLAN → ACTION → TEST → VERIFY → RESULT

## Binary result

RESULT ∈ {0,1}

- 1 = defined verification condition satisfied.
- 0 = defined verification condition not satisfied.

## Core rule

A result is not classified until the condition being tested is defined.

## TCGE/TXGE implementation layer

LOGIC → SPECIFICATION → CODE → EXECUTION → TEST → VERIFICATION → RESULT
