# BUCK -> BLOCK -> UNBLOCK -> UNLOCK

Date: 2026-09-26

Operator chain:

BUCK -> BLOCK -> UNBLOCK -> UNLOCK

Definitions:

- BUCK = resist or oppose a force/change.
- BLOCK = prevent passage or transition.
- UNBLOCK = remove the obstruction.
- UNLOCK = remove a lock so a permitted transition becomes possible.

State interpretation:

S0 -> BUCK -> RESIST -> BLOCK -> CLOSED -> UNBLOCK -> OPEN -> UNLOCK -> ACCESSIBLE

Invariant:

UNBLOCK != UNLOCK

Removing an obstruction does not itself establish authorization or access. Under the evidence-bound gate framework, UNLOCK remains subject to the evidence and authority required by the applicable gate.
